# **App Name**: CloudVault

## Core Features:

- User Authentication: Secure user authentication via Google and GitHub.
- File Upload: Upload files up to 100MB to cloud storage.
- File Viewing: View a list of stored files with associated metadata.
- File Download: Download stored files from the cloud.
- Free Storage: Provision 2GB of free storage for each user.

## Style Guidelines:

- Primary color: Clean blue (#3498db) to convey trust and security.
- Background color: Light blue (#e7f5ff) for a calm and professional feel.
- Accent color: Deeper blue (#2980b9) for interactive elements and highlights.
- Body and headline font: 'Inter', a sans-serif for a modern and neutral look.
- Use simple, clear icons to represent file types and actions.
- Minimalist design with ample white space to focus on content.
- Subtle transitions and animations for file uploading and downloading to enhance user experience.
